# AI Diploma Leaderboard Website

A static GitHub Pages website for an AI Diploma class.

## Sections

- Leaderboard
- Learning Week
- Resource Wall
- Best Explanation Gallery
- AI Word of the Week
- Group Cards & Achievements
- Announcements

## How to edit

Open `data.js` and edit:

- group names
- member names
- scores
- achievements
- weekly learning topic
- resources
- explanations
- word of the week
- announcements

## How to publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `data.js`, and `README.md`.
3. Go to repository Settings.
4. Open Pages.
5. Under Source, choose `Deploy from a branch`.
6. Choose `main` branch and `/root` folder.
7. Save.
8. GitHub will give you a public website link.
